Come leggere lo stato

Verde significa che una richiesta tecnica è riuscita, non che login reale, sincronizzazione, salvataggi o permessi siano certificati. I controlli programmati da GitHub possono essere ritardati; dati vecchi o mancanti non vengono mostrati come successi.

Dettagli tecnici su GitHub Actions. Non condividere password, dati personali o archivi nei report di errore pubblici.
